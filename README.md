# PageFeed

PageFeed 是一个“像刷信息流一样看公司 landing page，并用投资/增长视角拆解项目”的产品原型。

## Folder Structure

- `current-pwa/`：当前可运行的静态 PWA MVP，最近迭代的版本在这里。
- `docs/`：产品方案、实现方案和后续可以继续沉淀的文档。
- `archive/pagefeed-mvp-next-scaffold/`：早期 Next.js 脚手架尝试，暂时归档保留。

## Run Current MVP

```bash
cd /Users/iristang/Desktop/PageFeed/current-pwa
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```
